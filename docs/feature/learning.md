# 学習画面

## 仕様

- Learn タブで、学習するスキルとスキルノードを選択する。
- 学習選択画面は検索欄とスキル／難易度の絞り込みを中心に構成し、条件に一致する学習項目だけを表示する。
- 学習項目は名称と難易度を区切り線で表示する。説明、件数ラベル、注釈的な文章は表示しない。
- 最初の学習項目を初期選択し、「この内容で始める」から問題画面へ進む。
- ホームの再生ボタンから開始要求を受けた場合は、Learnタブへ切り替え、ホームタスクに登録された問題種別・言語・難易度に対応する問題画面を開始する。
- 問題数に終端は設けず、取得した問題を継続して出題する。問題画面は次のフィードバックまでの問題番号、5問単位の進捗、問題文、コード、四択を表示する。問題種別・言語・難易度のタグは表示しない。
- 選択肢を選ぶまでは回答ボタンを無効にし、回答後は正解、不正解、正解の選択肢、解説、獲得XPを表示する。
- 回答後は次の問題へ進み、5問回答するごとに、複数の候補からランダムに選んだ励ましのメッセージと正解数のフィードバックを表示する。
- フィードバック画面では、直近5問の問題タイトル、選択した回答、正解、不正解、解説を振り返れるようにする。獲得XPはフィードバック画面に表示しない。振り返りデータは現在の学習セッション中だけ保持し、画面を離れるかアプリを終了すると破棄する。
- フィードバック画面では、振り返り一覧の上に「一覧へ」と「学習を続ける」を横並びで表示し、「学習を続ける」を「一覧へ」より横長にする。「一覧へ」は学習項目の選択画面へ戻る。
- フィードバックから「学習を続ける」を選ぶと、進捗をリセットして次の5問へ進む。
- 問題画面に閉じるボタンは表示しない。
- 問題へ回答している間はボトムナビゲーションを表示しない。5問ごとのフィードバック画面では再表示する。
- 読み込みまたは回答送信に失敗した場合は、画面内にエラーメッセージを表示する。
- トップナビゲーションとボトムナビゲーションは既存の表示と挙動を維持する。
- ホーム画面と同じ白背景を使い、通常時の配色は黒、グレー、紫に絞る。正誤表示に限り緑と赤を使用する。
- 主要アクションボタンは既存画面と同じ紫、角丸14、高さ54を基本とし、一覧へなどの補助アクションは同じ寸法のアウトラインボタンで表示する。
- 学習選択画面はほかのタブと同じ画面タイトル「学習」を使い、カード型の囲みやグラデーションを使わず、検索／絞り込み、余白、区切り線で整理する。装飾用アイコン、英字見出し、サブタイトルは表示しない。

## APIとの対応

- 学習項目は `GET /v1/skills` のスキルとスキルノードを使用する。
- 選択したスキルノードの問題一覧を `GET /v1/questions?skill_node_id=...` で取得し、各問題の表示情報を `GET /v1/questions/{id}` で取得する想定とする。
- 回答は `POST /v1/questions/{id}/attempts` の `selected_keys` と `duration_ms` を送信し、`is_correct`、`correct_keys`、`explanation`、`xp_gained` を表示する。
- ホームからの開始では、タスクの設定スロットを問題取得フィルターへ変換する。現在は `MockLearnRepository.fetchQuestionsForTask()` がこの変換後の条件で問題を絞り込む。
- 現在は `LearnRepository` のモック実装を使用する。モックレスポンスもAPIのJSON形状からDTOを経由してドメインモデルへ変換する。
- API版へ接続するときは `LearnRepository` の実装を差し替え、画面Widgetへ通信処理やJSON固有の型を追加しない。

## 実装状況

スキル／学習項目の検索・絞り込みと選択、問題セットの開始、ホームタスクの設定に対応した問題の開始、四択回答、正誤と解説の表示、継続的な問題の進行、直近5問の振り返りを含む5問ごとのフィードバックをモックデータで実装済み。獲得XPは回答直後の結果パネルにのみ表示する。振り返りデータはセッション内のメモリだけで保持し、API通信の具体実装は未接続。
