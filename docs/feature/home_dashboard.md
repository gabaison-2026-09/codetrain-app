# ホームダッシュボード

## 仕様

- トップナビゲーションとボトムナビゲーションの間に、ホームのダッシュボードを表示する。
- カレンダーアイコンの右に当日の `月 / 日` を表示する。日付はホームデータの `activityDate` から生成する。
- 右上に、炎アイコンと連続学習日数を配置したオレンジ色の円弧ゲージを表示する。円弧の下側約30%は開け、今日のタスク5件に対する消化割合をゲージ長で表す。
- 再生ボタンの下に、選択中タスクへ登録された言語一覧と追加枠を表示する。
- タスク画面でホーム開始対象に設定した最大3件を、再生ボタンの左右スワイプで切り替える。再生ボタンを押すと選択中タスクの開始操作を行い、学習画面の問題を開始する。
- トップナビゲーションおよびボトムナビゲーションのレイアウト・描画は変更しない。
- 画面レイヤーはホーム本体、トップナビゲーション、ボトムナビゲーションの順に重ね、ナビゲーションを前面に表示する。
- ホーム本体の上端はトップナビゲーションの高さとステータスバー領域を考慮して配置する。
- 画面全体の背景色は白とする。
- ホーム本体には、白背景を保ったまま、ゆっくり回転する再生ボタン周囲の短い紫系の軌道線を追加する。
- 装飾は学習情報の視認性を妨げない範囲に限定し、グラデーションとカード型 UI は使用しない。
- 日と月の表示には同梱した `Jua` フォントを使用し、日を大きく、月をやや小さく表示する。
- 上部の日付・円弧ゲージは、左右にゆとりを持たせて配置する。狭い画面では日付部分のみを必要な範囲で縮小する。
- 再生ボタンは直径 `254`、枠線幅 `9` で表示する。周囲に短い紫系の軌道線をゆっくり回転させ、左右スワイプで当日の学習タスクを切り替えられるようにする。
- ホームの再生ボタンから学習を開始した場合は、Learn画面を下方向から軽く拡大しながらフェードインさせ、`480ms`以内で素早く遷移する。ボトムナビゲーションからの通常のタブ切り替えは既存の遷移を維持する。
- タスクごとに控えめなアクセントカラーを割り当て、再生円・再生アイコン・周囲の軌道線・タスクインジケーターへ反映する。色は画面側の固定パレット（紫・ティール・プラム）で管理し、言語アイコン固有の色は変更しない。
- 言語アイコンは `36` の大きさとし、各アイコンの間隔を `23` とする。
- 下部の言語アイコン列は選択中タスクに登録された言語一覧であり、タスクを切り替えると一覧全体をアニメーション付きで入れ替える。追加アイコンは言語一覧の右端に1個だけ、クライアント側で自動表示する。
- コンテンツ末尾の右下寄りに控えめな「オープンソースライセンス」リンクを表示し、使用素材のライセンス表示画面へ遷移できるようにする。
- タスクインジケーターは点の左右に薄い水平線を表示し、参考デザインの区切りを保つ。
- ホームから開始したタスクベース学習を5問完了してフィードバックへ進んだとき、当日のタスク消化数を1件増やし、連続日数ゲージの円弧を現在値から新しい値までアニメーション表示する。ホームが非表示の場合は、ホームへ戻った時点でアニメーションを開始する。
- タスク完了時は、表示中の画面全体にホームと同じ連続日数ゲージを拡大表示して一度見せ、間を置いてから現在の消化割合から次の割合まで円弧を素早くアニメーションさせ、満タン到達後と連続日数の切り替え後も約1秒見せてから自動的に消す。満タン未満は約3秒、満タン時は約5秒を目安とする。オーバーレイは操作を妨げない。
- 円弧が満タンになる場合は、ゲージが最大まで伸びた後に中央の連続日数を一度拡大してから翌日数へ切り替える。満タン未満では連続日数を変更しない。
- 当日のゲージがすでに満タンの場合は、追加のタスク完了イベントを受け取っても全画面ゲージアニメーションを表示しない。
- 現在の要素の下に、当月の学習日数と割合を表示する。10日・20日・月末を目盛りとして示し、31日ある月も上限は30日、2月は28日を上限とする。
- 月間進捗の日本語テキストには `Noto Sans Japanese` を使用する。割合はゲージの長さで表現し、数値や吹き出しは表示しない。
- タスク切り替えが成立したときだけ、軽い選択系の触覚フィードバックを発生させる。
- 再生開始中は、遷移中のホーム表示がタスク設定の読み込みで差し替わらないよう、選択中タスクの名称と言語アイコンを開始時点の内容で保持する。開始に失敗した場合は通常の表示へ戻す。
- タブ切り替え時もホーム画面の Widget と取得状態を保持し、画面遷移アニメーション開始時に初期モックデータへ戻らないようにする。ホームへ戻った時点で再生開始中の状態を解除し、再生ボタンとタスク切り替えを再び操作できるようにする。

## データ構成

- 表示データは `HomeDashboard` に集約する。
- `HomeDashboardRepository` をデータ取得の境界とし、現在は `MockHomeDashboardRepository` を使用する。
- Repository の選択と取得失敗時の初期表示データの注入は `CodeTrainApp` で行い、画面Widgetはモック実装へ直接依存しない。通信中は初期モックを表示せず、ローディングアニメーションを表示し、ダッシュボードとタスク設定が揃ってから表示する。API接続時は `homeRepository` にAPI版Repositoryを渡す。
- 再生ボタンの開始処理は `TaskLauncher` を境界とし、現在はモック実装、将来は `study_tasks.task_no` を使うAPI実装へComposition Rootで差し替える。
- タスク画面で設定したスロットは開始要求時に学習問題のフィルターへ変換し、問題種別・言語・難易度が一致する問題を開始する。ホームタスクの切り替え時は表示データとタスク設定を同じ順序で扱う。
- 将来の API 接続では `GET /v1/home` の `activity_date`、`tasks`、`monthly_progress`、`study_tasks`、`review.due_count` からホーム固有の表示モデルを組み立てる。`tasks` の `completed_at` を集計して円弧ゲージの消化割合を作り、`study_tasks` は1タスクに複数の言語を持つ形で表示する。全画面共通の連続学習日数は `GET /v1/me.progress.streak_days` を利用する。

## 構成

- 画面: `lib/features/home/presentation/home_tab_page.dart`
- 表示モデル: `lib/features/home/domain/home_dashboard.dart`
- Repository: `lib/features/home/domain/home_dashboard_repository.dart`
- モック実装: `lib/features/home/data/mock_home_dashboard_repository.dart`
- 開始処理の境界: `lib/features/task/domain/task_launcher.dart`
- フォント: `assets/fonts/Jua-Regular.ttf`、`assets/fonts/RussoOne-Regular.ttf`、`assets/fonts/NotoSansJapanese-Regular.ttf`
- 言語識別アセット: `assets/icons/programming_languages/`（C、C++、C#、Dart、Go、Java、JavaScript、Kotlin、PHP、Python、Ruby、Rust、Swift、TypeScript）。各言語の公式Devicon SVGを使用し、出典と追加ライセンス条件は `THIRD_PARTY_NOTICES.md` に記録する。
- ホーム画面の言語表示は `lib/shared/widgets/programming_language_icon.dart` を使用し、学習画面と同じ公式ロゴを表示する。言語ロゴ固有の色は変更しない。
- ライセンス表示画面は `lib/features/legal/presentation/open_source_licenses_page.dart` でアプリ内表示する。

## 実装状況

実装済み。現在日付を使ったモック表示、タスク消化割合の円弧ゲージ、タスクベース学習の5問完了時にホーム復帰後まで保持されるゲージ増加アニメーション、全画面に拡大表示して円弧を伸ばし満タン時に連続日数を増加させるタスク完了ゲージ演出、当月の学習進捗、控えめなセクション装飾、タスク画面で選択した最大3件の学習タスクのスワイプ切り替え、再生ボタンによる学習画面への遷移と問題開始、選択タスクに応じた公式言語ロゴ列、ライセンス表示画面へのリンクを表示している。復習導線は保留中。
