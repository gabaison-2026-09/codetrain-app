# ホームダッシュボード

## 仕様

- トップナビゲーションとボトムナビゲーションの間に、ホームのダッシュボードを表示する。
- カレンダーアイコンの右に当日の `月 / 日` を表示する。日付はホームデータの `activityDate` から生成する。
- 日付の下に過去3日・当日・未来3日の学習状況を示す丸を並べる。過去日は薄い緑（学習済み）または赤（未学習）、当日は紫、未来3日は灰色で表示する。
- 火のアイコンと連続学習日数を表示する。
- 再生ボタンの下に、選択中タスクへ登録された言語一覧と追加枠を表示する。
- トップナビゲーションおよびボトムナビゲーションのレイアウト・描画は変更しない。
- 画面レイヤーはホーム本体、トップナビゲーション、ボトムナビゲーションの順に重ね、ナビゲーションを前面に表示する。
- ホーム本体の上端はトップナビゲーションの高さとステータスバー領域を考慮して配置する。
- 画面全体の背景色は白とする。
- ホーム本体には、白背景を保ったまま、ゆっくり回転する再生ボタン周囲の短い紫系の軌道線を追加する。
- 装飾は学習情報の視認性を妨げない範囲に限定し、グラデーションとカード型 UI は使用しない。
- 日と月の表示には同梱した `Jua` フォントを使用し、日を大きく、月をやや小さく表示する。
- 上部の日付・連続学習日数は、参考デザインに合わせた大きさと間隔を保ち、左右にゆとりを持たせて配置する。狭い画面では日付部分のみを必要な範囲で縮小する。
- 連続学習日数は炎アイコンと文字の下辺を揃え、両者の間隔を `8`、右側の余白を `9` とする。数字は `Jua` の `34`、単位は標準フォントの `24` で表示する。
- 学習状況の丸は通常 `14`、選択中は `22` の大きさとし、各要素の間隔を `11` とする。
- 再生ボタンは直径 `254`、枠線幅 `9` で表示する。周囲に短い紫系の軌道線をゆっくり回転させ、左右スワイプで当日の学習タスクを切り替えられるようにする。
- タスクごとに控えめなアクセントカラーを割り当て、再生円・再生アイコン・周囲の軌道線・タスクインジケーターへ反映する。色は画面側の固定パレット（紫・ティール・プラム）で管理し、言語アイコン固有の色は変更しない。
- 言語アイコンは `36` の大きさとし、各アイコンの間隔を `23` とする。
- 下部の言語アイコン列は選択中タスクに登録された言語一覧であり、タスクを切り替えると一覧全体をアニメーション付きで入れ替える。追加アイコンは言語一覧の右端に1個だけ、クライアント側で自動表示する。
- タスクインジケーターは点の左右に薄い水平線を表示し、参考デザインの区切りを保つ。

## データ構成

- 表示データは `HomeDashboard` に集約する。
- `HomeDashboardRepository` をデータ取得の境界とし、現在は `MockHomeDashboardRepository` を使用する。
- Repository の選択と初期表示データの注入は `CodeTrainApp` で行い、画面Widgetはモック実装へ直接依存しない。API接続時は `homeRepository` にAPI版Repositoryを渡す。
- 将来の API 接続では `GET /v1/home` の `activity_date`、`tasks`、`weekly_activity`、`study_tasks`、`review.due_count` からホーム固有の表示モデルを組み立てる。`study_tasks` は1タスクに複数の言語を持つ形で、全画面共通の連続学習日数は `GET /v1/me.progress.streak_days` を利用する。
